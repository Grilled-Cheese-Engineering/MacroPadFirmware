# GCE ZMK Firmware Downloads

This repository contains all of our ZMK based firmware. Feel free to make changes to our configurations. Check out [zmk.dev](zmk.dev) to learn more.

## Boards

### 3x3 Macro Pad

A simple macro pad with a 3x3 matrix of keys and a single rotary encoder. Uses the Seeed Studio XIAO nRF52840 microcontroller. The board has support for both serial and bluetooth.

Find the build guide and additional files here: [3x3 Macro Board Build Guide](https://github.com/Grilled-Cheese-Engineering/3x3MacroPadExtras)
